# Контракт данных устройства и сессии (SDK для iOS и Android)

В прототипе мобильного SDK нет. Здесь описано, что SDK должен собирать и как это передаётся в API
(блок `session` в `POST /v1/score`). Признаки рассчитываются на устройстве, в антифрод уходят только
итоговые значения, без персональных данных.

| Поле | Как получить | Android | iOS | Для какого сценария |
|---|---|---|---|---|
| `device_id` | устойчивый идентификатор установки, переживающий переустановку, если это допускает ОС | Android ID + ключ в Keystore | identifierForVendor + Keychain | смена устройства, мультиаккаунты, чужие карты |
| `emulator` | признаки эмулятора: сборка, железо, датчики | Build.FINGERPRINT/HARDWARE, отсутствие датчиков | `targetEnvironment(simulator)`, модель | захват аккаунта, фермы аккаунтов |
| `rooted` | root / jailbreak / хуки | Play Integrity API, su, Magisk | App Attest / DeviceCheck, пути jailbreak | захват аккаунта |
| `remote_access_app` | запущено приложение удалённого доступа или идёт запись экрана | список процессов / AccessibilityService | `UIScreen.isCaptured` | социальная инженерия |
| `on_call` | идёт телефонный звонок во время операции | TelephonyManager.callState | CallKit `CXCallObserver` | социальная инженерия |
| `ip`, `ip_country` | IP на стороне бэкенда заказчика + GeoIP | — | — | захват аккаунта |
| `lat`, `lon` | грубая геопозиция, только с согласия клиента | Fused Location (coarse) | CoreLocation (reduced accuracy) | невозможное перемещение |
| `os` | платформа и версия | Build.VERSION | UIDevice.systemVersion | качество данных |

Требования:
- без согласия клиента геопозиция не собирается; поля, которых нет, просто не передаются;
- целостность данных SDK подтверждается аттестацией (Play Integrity / App Attest) на бэкенде заказчика;
- номера карт, телефонов и кошельков передаются только в виде хешей (см. `app/privacy.py`).
